# UI

The frontend is a Next.js 15 application deployed on Vercel.

**Live app:** [macysai.vercel.app](https://macysai.vercel.app)

**Source code:** `gui/` at the repo root (not duplicated here to avoid divergence).

Key routes:

| Route | Page |
|---|---|
| `/campaign-manager` | Merna's 10-step workflow workspace |
| `/start` | Create a new campaign (Start screen) |
| `/evidence` | Evidence screen (RAG docs, MCP tools, cascade lineage) |
| `/review` | Review screen (Approve / Edit / Reject / Rerun / Escalate) |
| `/impact` | Before GenAI vs After GenAI financial impact |
| `/evals` | DeepEval test results |
| `/docs` | M4 deliverable documents |
| `/story` | Storyboard presentation |
